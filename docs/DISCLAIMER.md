# 免责声明与服务条款

本文件是「萌新工具箱」（下称"本工具"）的免责声明与服务条款。
它同时是程序里那个「免责声明 / 服务协议」窗口的正本：窗口显示的内容就是这个文件
（编译时以资源形式内嵌进 `Mxx1Toolbox.exe`，两者永远一致）。
首次使用前请读一遍；继续使用即视为你已经读过并同意下面全部内容。

## 1. 这个工具是做什么的

- 主界面是一面**按钮墙**：点一下按钮，就启动一个已经做好的程序、脚本或系统功能。
  按钮由 `tools\*.json` 和 `bin-tools\<工具>\tool.json` 定义，加按钮不需要重新编译。
- 「系统工具」「应用管理」这两页调的是 **Windows 自带的界面和组件**（设备管理器、磁盘清理、
  任务计划程序、Windows 更新设置…），本工具不替它们做决定。
- 「隐私设置」和「常用设置」里的按钮会**写你本机注册表**（大多是 `HKEY_CURRENT_USER`
  下的值，需要管理员的少数会写 `HKEY_LOCAL_MACHINE`）
  （广告 ID、遥测、任务栏合并方式、右键菜单样式…），详见第 2 节。
- 「常用设置」里的「电源与笔记本」那一组能**看和改合盖 / 电源按钮 / 睡眠按钮的动作**
  （「桌面模式·合盖不睡」就是这个开关），还能出电池健康报告、查是谁按着不让电脑睡。
  改的动作落在**本机所有电源方案**上，改前先记原值、随时能还原，详见第 2 节。
- 「右键增强」会在你的资源管理器右键菜单里加这些项目：「解除文件占用」「一键解除占用」
  「常用功能 ▸」「复制文件名」「复制文件路径」「在此处打开终端 ▸」「图片转换 ▸」「图标提取 ▸」
  （每一条都有一对「装上 / 撤掉」按钮，撤掉只删本工具自己写的注册表键）。
- 「解除文件占用」（右键菜单项或主界面按钮）会查**是哪个程序占着这个文件**，
  并且（只在你勾选并确认之后）**结束那些进程**或**关掉它们持有的文件句柄**，详见第 2 节。
- 「一键解除占用」是同一件事的**不弹窗口版**：右键一下，它在后台查谁占着这个文件，
  查到就**直接结束那些程序**（**不问、没有确认框**），然后**在鼠标旁边弹一张小提示卡**说结果
  （几秒后自己消失；它不抢焦点、不占任务栏）。
  它自己那条线比上面那个更窄：系统关键进程、资源管理器（explorer.exe）、本工具自己一律不动；
  没同意过本条款时也一律不动（只写日志）。详见第 2 节。
- 「系统工具」「常用设置」「清理优化」里还有几颗按钮会**改本机的系统设置**：
  一键换 DNS、启动项管理、U 盘安全弹出、关掉系统代理、修复图标与缩略图缓存、
  修复桌面图标黑块、隐藏 / 恢复未激活水印、定时关机 / 重启 / 睡眠。每一颗都是
  **先记下原值 → 再写 → 读完核对**，能还原的都给出还原入口；需要管理员的会先弹一次 UAC。
  逐条说明见第 2 节。
- **定时关机 / 重启 / 睡眠**是交给 Windows 自己执行的：定好之后**就算你把工具箱关掉，
  到点也照样关机 / 重启 / 睡眠**；想取消要用工具箱里的「取消」，或者在命令行跑 `shutdown /a`。
- 本工具里**有些按钮会真的删东西**：无效快捷方式清理、空文件夹清理、重复文件查找
  （这三样默认删进回收站）、批量重命名（可撤销上一次）、右键菜单管理里的「删除」
  （先把那个键导出一份 `.reg` 备份）、修复图标与缩略图缓存（只删 Windows 会自己重建的缓存文件）。
  每一处在动手前都会把**「要动哪些」列给你确认**；能撤销的会写明怎么撤销。
- 「图片转换」「图标提取」这类按钮会在**源文件旁边生成新文件**，撞名时自动加 `-2`，
  **绝不覆盖原文件**；源文件夹写不进去时会退到桌面，并在提示卡上说明。
- 本工具**不扫描你的文档内容、不上传你的任何文件**；唯一会联网的是「检查更新」，
  只读公开的版本号（详见第 4 节）。

## 2. 它用到了哪些权限和系统位置

- **本身不提权**：`Mxx1Toolbox.exe` 以普通用户权限运行（清单是 `asInvoker`），
  不装服务、不装驱动、不加开机启动项、不建计划任务、不改回收站设置。
  清单里写着"需要管理员"的按钮（以及按住 Shift 点按钮）会**再用一次 UAC 把自己提权启动**，
  那一次是 Windows 弹的框，你可以拒绝。
- **按钮启动的程序**：就是你放进 `bin-tools\` 或者清单里指到的那些程序。
  它们的行为、权限和后果由它们自己负责 —— 本工具只是个启动器。
- 「隐私设置」/「常用设置」写的注册表位置：`HKEY_CURRENT_USER\Software\...` 下与隐私、
  资源管理器、任务栏相关的值。写入流程固定是
  **先记原值 → 再写 → 读回核对 → 可以一键还原**，原值记录在
  `%LOCALAPPDATA%\mxx1-toolbox\privacy-original.tsv` 与 `sysreg-original.tsv` 里
  （界面上有「查看设置改动」「还原设置改动」两个按钮）。
- 「常用设置」页里的「电源与笔记本」那一组（合盖与电源键动作 / 电源方案体检 / 电池健康报告 /
  谁在阻止睡眠 / 桌面模式·合盖不睡）用到的东西：
  - 「电源方案体检」「谁在阻止睡眠」是**只读**的：它们只是调系统的 `powercfg` 把现状念出来
    （`/requests` 那一段要有管理员权限才看得全），一个字节都不改；
    「电池健康报告」让 Windows 生成一份 `powercfg /batteryreport` 报告
    （HTML 文件写在本机 `%LOCALAPPDATA%\mxx1-toolbox\` 下，界面上有「打开报告」）。
  - 「合盖与电源键动作」「桌面模式·合盖不睡」（这两颗本身需要管理员，会再弹一次 UAC）
    会**改电源方案里"合上盖子 / 按电源按钮 / 按睡眠按钮"这三个动作**，而且是改成
    **这台电脑上所有的电源方案**，不只是当前生效的那一个 —— 因为有些程序（游戏加速器、
    厂商工具）会自己新建一个电源方案并切过去，只改当前那个的话，它一切走你的设置就等于没改。
  - 写入走 Windows 官方的那几条命令（`powercfg /setacvalueindex`、`/setdcvalueindex`、
    `/setactive`），不是本工具自己拼注册表值；**改之前先把每个方案的原值记在本机**
    （`%LOCALAPPDATA%\mxx1-toolbox\power-original.tsv`，记不下来就一个字都不改），
    写完**读回核对**，窗口里随时能一键「还原」。
  - ⚠️ 把合盖动作改成「不采取任何操作」之后，**合上盖子电脑既不睡、也不关机**。
    接显示器时这正是你要的效果，但要注意散热和耗电 —— 别盖着盖子就装进包里。
    「桌面模式·合盖不睡」那颗按钮就是这件事的开关：再点一次改回「关机」。
  - 那个窗口里还有一个「让控制面板里能看见『选择关闭盖子的功能』这一页」的勾：
    Windows 默认把这一页藏起来，它只**改显示与否**（走系统自己的
    `powercfg -attributes … ±ATTRIB_HIDE`），**不动任何动作**；它的原值也会记下来，
    「还原」时一并放回去。
- 「右键增强」写的注册表位置：`HKEY_CURRENT_USER\Software\Classes` 下**本工具自己的**
  `Mxx1*` 键（文件 / 文件夹 / 文件夹空白处 / 桌面空白处四个位置 + 一个共用的子菜单键），
  写 `HKCU` 所以**不需要管理员权限**；装完之后界面上随时可以撤掉，
  撤掉时**只删自己这几个键**（同名但不是本工具写的键会跳过并说明）。
- 「右键菜单管理」（「右键增强」页里那个按钮）读的是**你机器上真实的右键菜单**
  （含别的软件装的项，含 DLL 扩展项），并且只动**你勾选 / 点中的那一条**。
  它能做的四件事、以及各自写到哪里：
  - 「禁用 / 恢复」= 在那个项自己的注册表键里**加一个 / 删一个**隐藏开关值
    （键和标题一个字都不动，随时能恢复）；改完**立刻生效**，不用重启资源管理器；
  - 「删除」= 先把那个键**导出成一份 `.reg` 备份**（备份没成功就绝不删），然后才删键；
    备份放在 `%LOCALAPPDATA%\mxx1-toolbox\ctxmenu-backup\`，记录里可以「还原来」；
  - 「取得所有权」（只对少数被 Windows 保护的键）会**改那个注册表键、以及它下面写不动的子键**
    （通常就是那个键下面那个 `command` 子键）**的所有者**，并各追加一条「管理员：完全控制」
    ——动手之前先把**每一个要改的键**的原样权限存成一份 `.sddl`（存不下来就整件事不做），
    记录里随时能「还原权限」（逐个还回去）；**只加权限、不删原有权限**；
  - 「停用扩展 / 恢复扩展」（那一类项真正干活的是 DLL）写的是**用户区**的一份系统黑名单：
    `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Shell Extensions\Blocked`，
    值名就是那个扩展的 CLSID。**系统区的那一份（`HKLM`）本工具只读、一个字都不动**
    （那是别的工具或安装程序写的）。
    ⚠️ 这一类**要重启资源管理器才生效**：本工具为此给了一个「重启资源管理器」按钮
    （跑的就是「常用设置」页那一颗，会**先弹确认框**），它结束并重新启动 `explorer.exe` ——
    **任务栏和桌面会闪一下，所有已经打开的文件夹窗口会被一起关掉**（没保存的先存一下）。
    因为黑名单是**按 CLSID 认的**，停用一个扩展 = 它在**所有**右键位置一起消失。
  - 以上每一步都写进本机的动作记录（`%LOCALAPPDATA%\mxx1-toolbox\ctxmenu-actions.tsv`），
    界面上「动作记录」面板里能逐条撤销。
- 「解除文件占用」用到的东西：
  - 用系统的 **Restart Manager**（`rstrtmgr.dll`）和**只读**的句柄表扫描
    （`NtQuerySystemInformation`）查出是哪些进程占着文件，**只读，不改任何东西**；
  - 你勾选后可以**结束那些进程**（用 Toolhelp 快照连它们的子进程一起结束），
    或者用「强制解锁」**只关掉它们持有这个文件的句柄、不结束进程**；
  - 底线：只动你勾选的那些进程；`System` / `csrss` / `winlogon` / `lsass` 等系统关键进程
    会列出来但**禁止勾选**；查不出来时如实说查不出来，**不谎报「已解除」**。
  - 风险（你要知道）：结束进程 = 那个程序里没保存的东西会丢；关句柄 = 那个程序可能会报错、
    也可能存不上盘。所以这两件事都要过确认框，默认一个都不勾。
    系统进程和别的用户的进程动不了（需要管理员）；内核驱动自己持有的句柄谁都抽不掉。
- 「一键解除占用」用到的东西和上面完全一样（同一个查询、同一个结束进程的实现），
  **区别只有一条：它不过确认框、也不弹窗口**。所以它把底线收得更紧：
  - 只结束**确实占着这个文件的**和**它自己正在运行**（就是你要删的那个 .exe）这两类进程，
    连它们启动的子进程一起结束；
  - `System` / `csrss` / `winlogon` / `lsass` / `svchost` 等系统关键进程、
    资源管理器（explorer.exe）、本工具自己 —— **一律不动**；
  - **不是你自己账户的程序也一律不动**：系统服务、SYSTEM / 别的用户 / TrustedInstaller
    拥有的进程（判断的是"这个进程属于谁"，不是"它叫什么名字" —— 名字读不出来时同样不动）；
    系统报告为"服务"的、以及连名字都读不出来的进程，一律不动；
  - 只是"窗口里开着它"的程序不动（那种根本没锁住文件）；
  - 查到之后干了什么会写进本机日志（`%LOCALAPPDATA%\mxx1-toolbox\logs\`），
    并在**鼠标旁边弹一张小提示卡**说明结果：卡片**不抢焦点**（正在打字时字还是打进原来那个窗口）、
    **跟着鼠标走**、几秒后自己消失、点一下就关。万一没看清，日志里是完整的。
  - 风险（你要知道）：**它不会问你**。那些被结束的程序里没保存的东西会丢。
    拿不准的时候就用带窗口的那个「解除文件占用」（它会先列出来让你勾）。
- **会改动本机设置的按钮（逐条说清）**：
  - **一键换 DNS**：改的是当前网卡的 DNS 服务器（`netsh interface ipv4 set/add dnsservers`）。
    改之前把原来的 DNS 记在本机、改完**读回核对**，「还原」写回原值。
    **不改 IP、不改网关、不碰代理**。命令行那边只给只读的 `dns`（查询），要写只能从界面上点。
  - **启动项管理**：**只禁用、不删除**。注册表里的启动项，先把原值（含类型）记进
    `%LOCALAPPDATA%\mxx1-toolbox\startup-disabled.tsv`，再删掉那个值；启动文件夹里的文件
    是**挪到备份目录**。两样都能一键还原；Windows 自带的组件标灰、不给禁。
  - **U 盘安全弹出**：先用 Restart Manager 查**是谁占着这个盘**并列出来，
    你确认之后才结束它们（系统关键进程不给结束），然后锁卷、卸载卷、请求 Windows 弹出设备。
    **没弹出成功就如实说没成功**，不会假装已经弹出。⚠️ 等系统提示"可以安全移除"再拔。
  - **结束进程 / 结束整棵进程树**（「端口与进程」窗口里右键）：「结束这个进程」只动它一个；
    「结束它和它开的子进程」会把它启动的那一串一起结束（确认框里列出会一起没的 PID）。
    两种都有确认框，并提醒**对方没保存的数据会丢**；`System` / `explorer.exe` / 本工具自己不给结束。
  - **定时关机 / 重启 / 睡眠**：关机 / 重启调 Windows 自己的 `shutdown.exe`
    （倒计时由系统管，关掉工具箱照样执行，取消 = `shutdown /a`）；睡眠没有对应的系统命令，
    由工具箱启动的一个**隐藏后台进程**到点调 `SetSuspendState`。
    计时记录只有一行：`%LOCALAPPDATA%\mxx1-toolbox\timer.txt`。
    ⚠️ 到点就直接执行，**不会替你保存文档**；命令行故意没有"开始计时"这一项，只能在窗口里点。
  - **关掉系统代理**：只动浏览器那一层（WinINET 的 `ProxyEnable` / `ProxyServer` /
    `AutoConfigURL` / `AutoDetect` 四个值），写前记原值、写完读回，「还原」写回原样，
    写完通知浏览器重新读设置。**系统级的 WinHTTP 代理只读、只显示、一个字不改**；
    命令行只给只读的 `proxy status`。
  - **文件关联体检（修复「双击快捷方式说没有与之关联的应用」）**：往
    `HKLM\SOFTWARE\Classes`（系统默认那一层，这台机器所有用户共用）**补写缺失的关联登记**，
    只补一张写死的表里"缺的"那几项：`.lnk` 的快捷方式标记 `lnkfile\IsShortcut`、
    `.exe` / `.bat` / `.cmd` / `.com` / `.msi` / `.reg` / `.url` / `.pif` / `.scr` 的打开命令、
    双击文件夹的 `Folder\shell\open\command`。
    **用户自己改过、或别的软件设过的值默认一律不动**（报告里标出来；要覆盖得在窗口里另勾一次）。
    写之前把每一条的原值记进 `%LOCALAPPDATA%\mxx1-toolbox\assoc-original.tsv`
    （**记不下来就一个字都不改**），写完**逐项读回核对**；窗口里「还原成修复前」按记录
    把加进去的值删掉、被覆盖的值写回去 —— 哪一条后来被别人改过就**跳过那一行并写清原因**
    （不冲掉你的改动）。需要管理员权限、有确认框；命令行只给只读的 `assoc`，要写只能从界面上点。
  - **修复图标与缩略图缓存**：先结束资源管理器，再删 `IconCache.db` / `iconcache_*.db` /
    `thumbcache_*.db`（这些文件 Windows 会自己重建），然后重新拉起资源管理器。
    **只删缓存文件**，不碰你的个人文件；桌面和任务栏会闪一下。
  - **隐藏 / 恢复未激活水印**：写（或删）`HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\`
    `SoftwareProtectionPlatform\NoAcrWatermark`，需要管理员、有确认框。
    ⚠️ **不保证在你的系统上有效** —— 这个值名来自公开资料，我们没能在自己的机器上验证出水印真的消失；
    点「恢复」把值删掉就回到原样。
  - **修复桌面图标黑块（桌面 / 快捷方式图标左下角那块黑方块）**：删掉
    `HKEY_CURRENT_USER` 与 `HKEY_LOCAL_MACHINE` 两处 `SOFTWARE\Microsoft\Windows\CurrentVersion\`
    `Explorer\Shell Icons` 里**编号 `29`** 那个自定义图标值（「去掉小箭头」写进去的就是它）——
    删掉之后小箭头回到系统默认样子。写之前把原值（含类型）记进
    `%LOCALAPPDATA%\mxx1-toolbox\sysreg-original.tsv`，写完**读回核对**，并自动重启一次
    资源管理器（任务栏和桌面会闪一下；已经打开的文件夹窗口会被一起关掉）；
    「还原修复前的图标设置」按记录把原值写回去，**只还原这一项**，别的开关的记录不动。
    `Shell Icons` 里其它编号（有的美化工具会写 `77` / `179`）**只报告、一个字节都不动**。
    需要管理员权限、有确认框。
- 日志与设置：`%LOCALAPPDATA%\mxx1-toolbox\`（`logs\`、`settings.ini`、`tools.json`、
  `*.tsv`、`pinned.txt`、`recent.txt`）。全部只写在本机。
